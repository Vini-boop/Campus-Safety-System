========================================
TROUBLESHOOTING
========================================

NETWORK TIMEOUT ERRORS:
  Error: "getaddrinfo ENOTFOUND serviceusage.googleapis.com"
  
  Solution:
  - Check internet connection
  - Verify DNS settings
  - Try again with stable network
  - Disable VPN/proxy if active

PERMISSION ERRORS:
  Error: "Cloud Functions API not enabled"
  
  Solution:
  - Open Firebase Console
  - Navigate to project
  - Enable Cloud Functions API
  - Wait 5 minutes, then retry

BUILD ERRORS:
  Error: "Build failed"
  
  Solution:
  - Check index.js for syntax errors
  - Verify all require() statements
  - Run: node verify-deployment.js
  - Check firebase-debug.log
